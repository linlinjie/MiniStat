# MiniStat

MiniStat 是一个针对 Apple M1 的轻量原生 macOS 菜单栏监控工具。它显示 CPU、内存、系统盘占用、CPU 温度以及网络上下行速率。

## 特点

- 原生 Swift + AppKit，无第三方依赖
- 无 Dock 图标；系统指标本地采集；额度模块按需联网
- 菜单栏模块可单独隐藏
- 更醒目的加粗数值与放大标签，兼顾双行紧凑布局
- 系统指标可选 1、2、5、10、30 秒及 1、2、5 分钟，默认 2 秒
- 额度独立可选 10、30 秒及 1、2、5 分钟，默认 5 分钟；频率越高，联网和短时子进程开销越高
- 菜单提供“截图 / 录屏”按钮，打开 macOS 自带工具栏（Shift + Command + 5），不自动截图或开始录屏
- 可选开机启动，默认关闭
- 可从菜单直接打开 macOS 自启动应用列表进行查看和管理
- 按需查看应用流量 Top 10，可按当前速度或本次查看期间累计流量排序
- M1 温度读取失败时显示 `--°C`，不申请管理员权限
- 独立的蓝青渐变应用图标，包含心跳、仪表盘和三段负载柱

## 构建

仅需 Apple Command Line Tools：

```sh
cd MiniStat
./test.sh
./build.sh
```

工程同时保留标准 `Package.swift`，在安装了完整 Xcode 的开发环境中也可以使用 `swift test` 和 `swift build`。当前仅有 Command Line Tools 的机器请使用上述脚本。

构建脚本会从 `Packaging/AppIcon.png` 自动生成多尺寸 ICNS 资源；系统 `iconutil` 不可用时也无需额外依赖。

构建结果位于上级目录的 `outputs/MiniStat.app`，应用压缩包为 `outputs/MiniStat-0.3.0-arm64.zip`，源码包为 `outputs/MiniStat-0.3.0-source.zip`。

首次使用可直接打开构建出的应用；长期使用建议将其拖到 `/Applications`。点击菜单栏指标可调整显示模块、刷新频率和开机启动。

## AI 额度（0.3.0）

菜单“额度显示（剩余）”提供关闭、仅 Codex、仅 Cursor、两者同时显示，选择自动保存。“额度刷新频率”独立设置，默认每 5 分钟查询一次，可从“额度详情与连接”手动刷新、查看重置时间。上一次查询未完成时跳过该软件的新查询，关闭额度显示时停止额度定时器。

Codex 使用本机 app-server 的 account/rateLimits/read，查询结束退出子进程；菜单栏分开展示 CODEX 5H（5 小时）和 CODEX 7D（周）剩余额度。按接口实际窗口时长识别，不把 primary/secondary 的位置硬编码成固定周期；缺失窗口显示 --%。

Cursor 使用与 Cursor CLI 相同的 /usr/bin/security 路径读取指定登录项（cursor-access-token / cursor-user）。凭据只通过进程内存与管道流转，不写文件、不打印、不放入命令参数；不修改钥匙串访问权限。子进程 5 秒超时、输出上限 64KB；读取失败、超时或接口返回 401/403 时暂停后续自动读取，暂停状态跨重启保存。登录后点击“重试 Cursor 连接”才能恢复。如果系统的访问规则改变，系统工具仍可能要求授权；本程序不承诺绕过授权，但不会无限自动重试。

Cursor 仅向 https://api2.cursor.sh 查询，不跟随重定向。此接口非公开稳定 API，厂商更新可能需要适配。没有常驻 helper；使用前先安装 Cursor CLI 并执行 agent login。

`--%` 表示未获取或已过期；失败后的缓存附加 `*`，15 分钟后弃用，到重置时间也不推测为 100%。禁用的软件不再安排查询；在途查询受超时约束，Cursor 凭据读取和网络阶段的时限分别为 5 秒与 18 秒（另有短暂退出清理）。额度不包含额外按量付费余额。

可运行应用内可执行文件的 `--quota-check` 参数验证连接，只输出额度摘要或错误，不输出凭据。

## 指标定义

- CPU：Mach CPU tick 的区间使用率。
- MEM：活动内存、驻留内存和压缩内存之和，占物理内存的比例。
- SSD：根 APFS 卷已使用容量比例。
- TEMP：优先读取 M1 SMC 核心键；不可用时读取 Apple Silicon HID CPU 核心传感器，并计算有效读数平均值。
- NET：所有已启用 `en*` 物理接口的累计字节差值。

温度读取依赖未公开的 AppleSMC 接口，未来系统升级可能令其不可用；其他指标不会受此影响。

应用流量列表通过系统自带的 `nettop` 读取按进程统计，不需要管理员权限。只有列表窗口打开时才会每秒采样；窗口关闭后子进程立即结束，因此累计值从每次打开列表时重新计算。系统进程或应用 helper 可能以进程名称单独显示。

## 0.1.0 系统监控部分实测（不含额度查询）

在 `MacBookPro17,1 / M1 / macOS 26.5` 上，应用物理内存 footprint 稳定约 13MB，2 秒刷新时进程 CPU 约 1.0%。调用栈显示主要成本来自 macOS 26 对动态菜单栏内容生成系统快照；选择 5 秒刷新可进一步降低唤醒和绘制开销。`ps` 的 RSS 会把 AppKit/Swift 共享映射计入，观测值约 42–47MB，不代表应用私有内存。
